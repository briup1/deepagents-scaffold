# 工程结构规范


## 一、总体架构原则

- **约定优于配置**：目录即规范，物理结构强制逻辑分层。
- **单向依赖**：上层可依赖下层，严禁反向依赖（`tests/test_layering.py` AST 扫描强制）。
- **AI 友好**：任何模块的位置可预测，AI 不需要猜。

## 二、Monorepo 总体结构

```
deepagents-scaffold/
├── config.yaml / config.verify.yaml / config.test.yaml   # 配置（唯一事实来源，SCAFFOLD_CONFIG_PATH 切换）
├── src/
│   ├── scaffold/        # Python 后端包
│   └── web/             # React 前端子项目
├── tests/               # 后端 pytest（e2e/ 子目录为端到端）
├── scripts/             # dev.sh / stop_dev.sh / verify_dev.sh 等运维脚本
├── docs/                # 项目文档（harness/ 为 AI 规范体系）
├── data/                # SQLite 数据目录（不入库）
└── logs/                # 运行日志（不入库）
```

## 三、后端工程结构（Python / FastAPI / DeepAgents）

```
src/scaffold/
├── api/           # 网关层：FastAPI 路由（routers/）与 HTTP 中间件（middleware/）、AG-UI 端点（ag_ui.py）
├── core/          # DeepAgents 集成层：工具加载（tools.py）、技能发现（skills.py）、子 Agent 构建（subagents.py）
├── infra/         # 基础设施层（框架无关）：config/ models/ logging/ history/ artifacts/ prompts/
│                  #   middleware/（Agent 中间件 + Deer-Flow 适配器）sandbox/ extraction/ memory/
├── plugins/       # 扩展层：自定义工具（tools/）与 SKILL.md 技能（skills/），在 config.yaml 注册
└── runtime/       # 运行时编排：Agent 工厂与注册表（agents.py）、通道路由（channel_router.py）
```

**调用链**：`api(router) → runtime(Agent 工厂) → core(工具/技能) → infra(配置/模型/持久化)`

| 层 | 职责 | 禁止事项 |
|----|------|----------|
| api | 路由、参数校验、SSE 端点、HTTP 中间件（认证/限流/请求 ID/错误兜底） | 禁止直接写库；禁止 import `scaffold.core` |
| runtime | 装配 Agent：模型、工具、中间件链、子 Agent、技能、记忆、后端 | 禁止包含业务逻辑 |
| core | DeepAgents SDK 集成：工具/技能/子 Agent 的加载与校验 | 禁止 import `scaffold.api` |
| infra | 框架无关基础设施：配置、模型工厂、日志、SQLite 仓库、沙箱 | 禁止 import `scaffold.core` / `scaffold.api` |
| plugins | 工具与技能的实现载体 | 工具必须 async + kwargs（红线 1） |

## 四、前端工程结构（React / TypeScript / Vite）

```
src/web/src/
├── api/           # API 封装层：auth.ts（token + apiFetch）、threads.ts、copilotkit.ts、files.ts、historyAgent.ts
├── catalog/       # Generative UI 组件目录：types / createCatalog / GenerativeUIContext / __tests__
├── components/    # 组件：AgentSelector、Sidebar、ThreadList、ErrorBoundary、FileUploadDropzone、ui/（catalog 渲染组件）
├── hooks/         # useThreads、useGenerativeUITool、useGenerativeUIAction
├── App.tsx        # 根组件：Agent 选择、新建会话、CopilotKit Provider
└── main.tsx       # 挂载入口（StrictMode + ErrorBoundary）
```

**前端分层**：`api 封装层 → hooks → components`，组件禁止直接 fetch（红线 7）。

## 五、代码提交规范（Conventional Commits）

```
<type>(<scope>): <subject>

type: feat | fix | docs | style | refactor | test | chore | perf
```
- 一次提交只做一件事；提交信息用中文描述清楚"为什么"。
- 分支模型：`main` 受保护；功能分支 `feat/<主题>`、修复分支 `fix/<主题>`，合入 `main`。
