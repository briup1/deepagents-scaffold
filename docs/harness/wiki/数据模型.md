# 数据模型


## 1. 数据库设计规范
- 存储：SQLite（`config.yaml` `database.sqlite_dir`，默认 `./data`），异步访问用 aiosqlite；LangGraph checkpoint 使用 `langgraph-checkpoint-sqlite`（AsyncSqliteSaver）。
- 表名前缀：❓ 缺省决定——维持现状**无前缀**；表名/字段小写下划线。
- 必备字段：各表自带 `created_at`/`updated_at`（TEXT 时间戳）；无外键级联以外的逻辑删除标记。
- 表结构变更：只能写入对应 repository 的 `migrate()`（`CREATE TABLE IF NOT EXISTS` + `PRAGMA user_version` 递增），禁止外部脚本改库。

## 2. 核心表结构（来源：`infra/history/repository.py`、`infra/artifacts/repository.py`）

### 2.1 threads —— 会话线程
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| thread_id | TEXT | 主键 | PK |
| agent_id | TEXT | 绑定 Agent 名称 | NOT NULL |
| user_id | TEXT | 属主 | NOT NULL，索引 idx_threads_user_id |
| title | TEXT | 会话标题 | 可空 |
| created_at / updated_at | TEXT | 时间戳 | NOT NULL，updated_at 有索引 |

### 2.2 messages —— 会话消息
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| message_id | TEXT | 主键 | PK |
| thread_id | TEXT | 归属线程 | FK → threads ON DELETE CASCADE，索引 idx_messages_thread_id |
| run_id | TEXT | AG-UI 运行 ID | 可空 |
| role | TEXT | user/assistant/system/tool | NOT NULL |
| content / name / tool_call_id | TEXT | 消息内容 | 可空 |
| tool_calls | TEXT | JSON 序列化 | 可空 |
| created_at | TEXT | 时间戳 | NOT NULL |

### 2.3 extraction_tasks —— 抽取任务
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| task_id | TEXT | 主键 | PK |
| thread_id | TEXT | 归属线程 | FK → threads，索引 idx_extraction_tasks_thread_id |
| user_id | TEXT | 属主 | NOT NULL，有索引 |
| status | TEXT | 状态机见 `wiki/领域术语.md` 2.1 | NOT NULL |
| requirements | TEXT | JSON 抽取目标 | 可空 |
| script_artifact_id | TEXT | 脚本工件 | 可空 |
| extracted_artifact_id | TEXT | 结果工件 | 可空 |
| validation_report | TEXT | JSON 验证报告 | 可空 |
| run_count | INTEGER | iterate 执行次数 | DEFAULT 0 |
| created_at / updated_at | TEXT | 时间戳 | NOT NULL |

### 2.4 extraction_templates —— 抽取模板
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| template_id | TEXT | 主键 | PK |
| user_id | TEXT | 属主 | NOT NULL，索引 idx_templates_user |
| name | TEXT | 模板名 | NOT NULL |
| goal | TEXT | JSON 抽取目标 | NOT NULL |
| script | TEXT | 复用脚本 | NOT NULL |
| fingerprint | TEXT | JSON 结构指纹 | NOT NULL，含签名索引 idx_templates_signature |
| source_file_name | TEXT | 来源文件名 | 可空 |
| created_at / updated_at | TEXT | 时间戳 | NOT NULL |

### 2.5 artifacts —— 工件元数据（文件本体在 `stored_path`）
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| artifact_id | TEXT | 主键 | PK |
| thread_id | TEXT | 归属线程 | NOT NULL，索引 idx_artifacts_thread_id |
| user_id | TEXT | 属主 | NOT NULL，索引 idx_artifacts_user_id |
| artifact_type | TEXT | upload/script/extraction/report/normalized | NOT NULL，复合索引 (thread_id, artifact_type) |
| original_name / mime_type | TEXT | 原始文件名 / MIME | 可空 |
| stored_path | TEXT | 文件存储路径 | NOT NULL |
| size_bytes | INTEGER | 大小 | DEFAULT 0 |
| created_at | TEXT | 时间戳 | NOT NULL |
| metadata | TEXT | JSON 附加信息 | DEFAULT '{}' |

## 3. 缓存与消息队列
- 本项目无 Redis / 消息队列（❓ 维持现状）；禁止在未评审的情况下引入。
- LangGraph checkpoint SQLite 由 `AsyncSqliteSaver` 自建 schema，不归 `migrate()` 管理，禁止手工改其表。

> 维护：新表/新字段由 harness-sync 反补登记。
