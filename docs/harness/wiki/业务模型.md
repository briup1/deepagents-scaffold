# 业务模型


## 1. 领域划分

### 1.1 网关与 Agent 运行时域
- **职责**：FastAPI 网关、AG-UI SSE 端点、Agent 工厂与注册表、中间件链、子 Agent、记忆、通道适配。
- **核心实体**：Agent（按 harness profile 注册）、Harness Profile、工具、中间件、子 Agent 定义（见 `wiki/领域术语.md`）。
- **代码归属**：`src/scaffold/api/`、`src/scaffold/runtime/`、`src/scaffold/core/`。

### 1.2 数据抽取域
- **职责**：Excel/文件上传 → 规范化 → 生成抽取脚本 → 沙箱执行 → 验证 → 模板沉淀。
- **核心实体**：ExtractionTask（状态机见 `wiki/领域术语.md` 2.1）、ExtractionTemplate、Artifact（upload/script/extraction/normalized）。
- **代码归属**：`src/scaffold/plugins/tools/`（工具）、`src/scaffold/infra/extraction/`、`src/scaffold/infra/sandbox/`。

### 1.3 历史会话与工件域
- **职责**：线程/消息持久化、LangGraph checkpoint、工件元数据与文件存储，多用户属主隔离。
- **核心实体**：Thread、Message、Artifact。
- **代码归属**：`src/scaffold/infra/history/`、`src/scaffold/infra/artifacts/`。

### 1.4 通道域（可选启用）
- **职责**：飞书 / Slack 等 IM 平台接入（config.yaml `channels:` 控制，默认关闭）。
- **代码归属**：`src/scaffold/runtime/channel_router.py`。

## 2. 核心业务流程

### 2.1 `/agent` SSE 流式对话链路
- 时序：前端 HttpAgent → `POST /agent/{agentId}`（ag-ui 请求体）→ HTTP 中间件链（CORS→Auth→RequestId→RateLimit→Logging→ErrorHandler）→ 历史持久化监听器 → LangGraph Agent（模型→工具→中间件）→ SSE 事件流回前端。
- 关键不变量：消息落库必须关联 `thread_id`/`run_id`/`user_id`；未认证请求在 AuthMiddleware 层 401，不进入 graph。

### 2.2 数据抽取流水线
- 时序：上传（artifact_type=upload）→ 异常信号检测（merged/strikethrough）→ normalize（artifact_type=normalized）→ 模板匹配快路径 / 委派 extraction_coder → generate_extraction_code（task: goal_setting）→ run_extraction_script iterate 模式调试（≤8 次）→ finalize 落盘（code_generated → validating）→ validate_extraction_result（→ success/failed）。
- 关键不变量：用户代码只在沙箱执行（60s / 512MB）；iterate 不落盘工件；模板归属 user_id，不可跨用户命中。

### 2.3 历史会话持久化
- 时序：每个 ag-ui 请求的消息经 `api/stream_listeners.py` 写入 messages 表；threads 表维护会话元数据；checkpoint 由 AsyncSqliteSaver 管理。
- 关键不变量：线程属主不可变更（`ensure_thread` 已存在不更新属主）；非属主访问线程返回 404 语义（属主查询与授权层区分见 `wiki/接口协议.md`）。

## 3. 领域服务
- `HistoryRepository`：线程/消息/抽取任务/模板持久化（infra/history）。
- `ArtifactRepository`：工件元数据 + 文件存取（infra/artifacts）。
- `create_agent` / `get_agent` / `list_agents`：Agent 装配与注册表（runtime/agents）。
- `build_middleware_chain`：Agent 中间件链装配（infra/middleware）。
