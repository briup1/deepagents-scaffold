# 接口协议规范


## 1. REST API 设计规范
- 资源命名：小写、复数、层级表达归属（如 `/api/threads/{thread_id}/messages`）。
- 动词用 HTTP 方法表达：GET 查 / POST 增 / DELETE 删；写操作必须鉴权。
- 版本策略：❓ 维持现状——**无版本前缀**（`/api/...`），如未来破坏性变更再引入 `/api/v2`。

## 2. 响应结构（现状决策：不引入 `{code, message, data}` 包裹）
- **成功**：直接返回 Pydantic `response_model` 序列化对象（如 `ThreadsListResponse`、`ThreadResponse`）。
- **错误**：统一结构，由 `ErrorHandlerMiddleware` 兜底：
  ```json
  { "detail": "Internal server error", "request_id": "req-xxx", "type": "ValueError" }
  ```
- 业务错误码体系：**不引入**（❓ 用户已确认）；错误语义用 HTTP 状态码表达，排查细节进日志不进响应。

### 2.1 HTTP 状态码使用
| 状态码 | 场景 |
|--------|------|
| 200 | 成功 |
| 401 | 未认证 / token 失效（AuthMiddleware，前端收到后清 token 回登录页） |
| 403 | 已认证但越权（当前实现中非属主线程按 404 处理，403 保留给未来的属主可见场景） |
| 404 | 资源不存在或非属主线程 |
| 500 | 未捕获异常（统一结构，带 request_id） |

### 2.2 多用户语义
- `auth.enabled: false` 或未带 token 时 `user_id = "default"`（本地开发兼容）。
- `auth.enabled: true` 时按 `X-API-Key` 查 token→user_id 映射；线程/工件/模板查询一律按 user_id 隔离。

## 3. 鉴权
- 方式：`X-API-Key` 请求头；token→user 映射来自 `config.yaml` `auth.users`（token 用 `$ENV_VAR`，缺失启动失败）。
- 前端统一由 `apiFetch` 注入；**不采用**根 CLAUDE.md 早期 `SCAFFOLD_API_KEY` 单 Key 表述（以 auth 段为权威，❓ 用户已裁决）。

## 4. 分页与排序
- 请求：`limit`（默认 50，上限 200）、`offset`（默认 0），`sort` 暂无支持。
- 响应：`{ threads: [], total: n }`（total 为过滤后总数）。

## 5. 核心接口清单
| 接口 | 方法 | 说明 | 鉴权 |
|------|------|------|------|
| `/health` | GET | 健康检查 | 否 |
| `/agent`、`/agent/{agentId}` | POST | AG-UI SSE 流式对话端点（单 Agent 别名 `/agent` 保持兼容） | 是 |
| `/api/agents/` | GET | 列出已注册 Agent | 是 |
| `/api/agents/{agent_id}/threads` | DELETE | 清空当前用户该 Agent 的全部会话 | 是 |
| `/api/threads/` | POST/GET | 创建线程 / 列出线程（支持 `agent_id`、`limit`、`offset`） | 是 |
| `/api/threads/{thread_id}` | GET/DELETE | 线程详情 / 删除（含级联消息） | 是 |
| `/api/threads/{thread_id}/messages` | GET | 线程消息列表 | 是 |
| `/api/threads/{thread_id}/state` | GET/POST | LangGraph 状态读/写（按用户隔离） | 是 |
| `/api/files/upload`、`/api/files/`、`/api/files/{artifact_id}`、`/api/files/{artifact_id}/download` | POST/GET | 工件上传 / 列表 / 详情 / 下载 | 是 |
| `/api/tools/` | GET | 列出已注册工具 | 是 |

> 维护：新接口由 harness-sync 反补登记；变更须同步前端 `src/api/` 封装类型。
